# Discord Release Copy

Discord 發布文案應讓人能快速看懂「這是什麼、主要改了什麼、去哪裡下載」。一般工具或軟體以約 300～500 字為參考，不用為了湊格式塞入無關內容。

常用結構：

```markdown
**<Project Name>**
<一句話簡介>

## 主要內容
- <feature / change>

## 連結
[`Github 庫`](<repo>)
[`安裝最新`](<download>)
[`全部版本`](<releases>)
```

如果版本很多，不在 Discord 逐條列完整歷史；保留最近幾個重要版本，其餘導向 Releases 頁面。

Minecraft 機器、建築或結構分享可以採更精簡的「特點 / 注意 / 下載」形式，不必硬套一般軟體介紹。
