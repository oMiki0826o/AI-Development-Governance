# License Template Policy

預設使用者沒有另行指定時，可採 MIT；若 Repository 已存在 License，沿用既有授權，不自行替換。

## MIT

MIT 全文以正式標準文字為準，Copyright 年份與作者替換成實際資料。

## 其他授權

若指定 Apache-2.0、GPL-3.0、BSD-3-Clause、MPL-2.0 或其他 License：

1. 確認正確 SPDX identifier。
2. 使用 SPDX 或其他可靠官方來源的標準全文，不憑記憶改寫或刪節。
3. 同步 README 的授權章節與 License badge。
4. 若上游程式碼有授權義務，先確認衍生作品需要保留的 Notice、Copyright 或其他條件。

不確定正式條文時，先取得可靠來源，而不是自行拼出一份「看起來像 License」的文字。
