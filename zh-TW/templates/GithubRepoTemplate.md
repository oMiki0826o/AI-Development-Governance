# GitHub Repository Template

這是 GitHub 發布文件的入口，不再把 README、LICENSE、`.gitignore`、Discord 文案與 Repo Description 全部塞在同一份巨型模板。

依需求讀取對應文件：

- README：[`github/readme.md`](./github/readme.md)
- LICENSE：[`github/license.md`](./github/license.md)
- `.gitignore`：[`github/gitignore.md`](./github/gitignore.md)
- Discord 發布文案：[`github/discord-release.md`](./github/discord-release.md)
- GitHub About / Description：[`github/repo-description.md`](./github/repo-description.md)

## 共同原則

- 能從 Repository 確認的資訊先自行確認，不重複詢問。
- 不得用 `[TODO]`、虛構 Badge、假 Release、假圖片或不存在的安裝指令補空白。
- 未確認且會實質改變輸出的資訊，依 `rules/decision.md` 詢問。
- README、License badge 與實際 LICENSE 的 SPDX 標示要一致。
- 內容以目前實際專案為準，不把未完成計畫寫成已存在功能。

原始 v1.3.0 單檔模板已拆分到上述文件；語意與使用習慣保留，但避免未來維護單一大型模板時發生內容漂移。
