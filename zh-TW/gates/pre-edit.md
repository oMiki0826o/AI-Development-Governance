# Pre-edit Gate

- **Gate ID**: `GATE-PRE-EDIT`
- **Actor**: 執行本次修改的 Agent 或開發者
- **Evidence**: 已讀取的關鍵檔案、已確認的需求、需要時的使用者決策
- **Blocking**: 是。高風險未知事項或可能覆蓋既有工作時不得開始修改

開始修改前確認：

- [ ] 已理解目前需求與完成條件（`CORE-001`）。
- [ ] 已讀取與修改直接相關的架構、入口、caller / callee、config 或 tests（`ENG-001`）。
- [ ] 已區分已確認事實、推論與未驗證事項（`CORE-002`, `CORE-003`）。
- [ ] 已界定修改 Scope，沒有把無關重構混入任務（`CORE-005`）。
- [ ] 需要詢問或明確授權的事項已依 Decision Rules 處理。
- [ ] 新抽象若存在，已通過 `CONV-001` / `CONV-004` 的必要性檢查。
- [ ] 不會覆蓋或刪除未確認的既有修改（`CORE-007`）。
